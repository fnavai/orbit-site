# orbit-site

Landing page do Orbit, publicada pelo GitHub Pages.

- Site estático: tudo em `index.html` (HTML, CSS e JS). O 3D usa three.js 0.170 pelo jsDelivr e as fontes vêm do Google Fonts.
- O botão de download aponta para os releases públicos de https://github.com/fnavai/orbit-versoes.
- "Criar conta" e o mural de melhorias ainda são só interface (as contas chegam na v3).

## Publicar

Settings → Pages → Source: "Deploy from a branch", branch `main`, pasta `/ (root)`.
O endereço fica https://fnavai.github.io/orbit-site/.
